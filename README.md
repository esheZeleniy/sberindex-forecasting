# Прогнозирование потребления и детекция шоков в муниципалитетах РФ

## Описание решения
Проект направлен на решение задачи раннего выявления структурных изменений (шоков) и прогнозирования безналичных потребительских расходов на уровне муниципалитетов (на основе данных СберИндекса).

Для анализа были отобраны крупнейшие муниципалитеты. Целевая переменная — агрегированные расходы по категории «Все категории»[cite: 10, 11].

## Методология
1. **Детекция точек разладки:** Использована библиотека `ruptures`[cite: 12]. Применен алгоритм `Pelt` (модель `rbf`, параметр штрафа `pen=2.0`)[cite: 10, 11]. Метод позволил автоматически выявить макроэкономические шоки: июнь 2023 г. (начало жесткой ДКП) и март 2024 г. (фискальный импульс)[cite: 9].
2. **Прогнозирование:**
   * **Baseline:** `Prophet` — для оценки долгосрочного линейного тренда и годовой сезонности[cite: 11, 12].
   * **Advanced Model:** `LightGBM` — для адаптивного прогнозирования с учетом авторегрессии (`lag_1`, `lag_3`) и пространственного потенциала муниципалитета (`market_access`)[cite: 11, 12].
3. **Валидация:** Обучение проводилось на первых 12 месяцах, тестирование — на последующих 12. Метрики (MAE, R²) рассчитывались на горизонтах 1, 3, 6 и 12 месяцев[cite: 10, 11].

## Структура репозитория
* `main.py` — основной пайплайн загрузки данных, поиска шоков, обучения моделей и расчета метрик[cite: 11].
* `config.yaml` — конфигурационный файл с гиперпараметрами моделей и путями к данным[cite: 10].
* `requirements.txt` — список зависимостей для развертывания окружения[cite: 12].
